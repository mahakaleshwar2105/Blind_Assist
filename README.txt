SIGHTASSIST 3D WEBSITE
======================

Open index.html in a modern browser.

Features:
- Responsive landing page
- Interactive Three.js 3D smart-glasses concept
- Drag to rotate and wheel/pinch to zoom
- Features, workflow, technology and roadmap sections
- No build step required

The site loads Three.js from jsDelivr, so an internet connection is needed for the 3D viewer and Google Fonts.
Replace hello@example.com in index.html with your contact address.
